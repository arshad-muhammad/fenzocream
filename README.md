# FENZO — Haute Bio-Active Facial Cream & Skincare

A luxury, high-performance editorial landing page and shopping experience for **FENZO Haute Skincare**. Engineered with fluid responsive layouts, authentic liquid glass aesthetics, and lightweight GSAP-powered motion.

---

## ✨ Features

- **Liquid Glass Floating Navigation**:
  - Multi-tier specular reflections, authentic blur refraction (`backdrop-filter: blur(36px) saturate(210%)`), and obsidian cart badge.
  - Responsive mobile drawer sheet with smooth transitions and click-outside dismissal.
- **Jewel Ruby Red Accent System**:
  - Sophisticated ruby tones (`#9B111E`, `#660511`) throughout accents, glowing pulse badges, and the dedicated full-bleed testimonials showcase.
- **Interactive Product Catalog**:
  - Dynamic product tab switcher for Hydra-Luxe Recovery Cream, Cellular Peptide Radiance Cream, Botanical Night Infusion, and The Discovery Trio.
  - Real-time cart drawer with complimentary shipping threshold tracker.
- **GSAP Motion & Smooth Native Scrolling**:
  - Hardware-accelerated 3D tilt scrub and floating animations powered by GSAP 3.12 and ScrollTrigger.
  - Zero scroll locks; native smooth browser scrolling.
- **Mobile-First Responsiveness**:
  - Fluid clamp typography and responsive grid systems tailored for viewports from 375px up to 4K displays.
- **Zero AI Aesthetics**:
  - Focus on dermatology, bio-identical ceramides, and pure botanical formulation.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3** (Custom design system with CSS custom properties)
- **Vanilla JavaScript (ES6+)** (Cart state, product switching, accordion, mobile navigation)
- **GSAP 3.12 & ScrollTrigger** (Hardware-accelerated animations via CDN)

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via a local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js npx
npx serve .
```

Navigate to `http://localhost:3000` to view the experience.
